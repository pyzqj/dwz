# 🚀 引流宝 EdgeOne 原生版 (短网址 & 群活码)

本项目是专为 **腾讯云 EdgeOne Pages (Makers)** 打造的高性能轻量化私域流量管理系统。项目全面升级为 EdgeOne 云原生无服务架构，**严格仅保留「短网址」与「群活码」两大核心功能**。

数据库采用 **腾讯云 EdgeOne KV**（[产品文档](https://cloud.tencent.com/document/product/1552/127420)），文件与群二维码存储采用 **腾讯云 EdgeOne Blob**（[产品文档](https://cloud.tencent.com/document/product/1552/131425)），零服务器运维开销，依托全球边缘节点实现毫秒级响应。

---

## 🌟 核心特性

### 1. 🔗 智能短网址（dwz）
- **⚡ 一键极速生成**：**只需直接粘贴长链接，回车或点击按钮，系统即可自动生成 6 位短链并秒级自动复制到剪贴板**；
- **自动智能标题**：长链接自动解析域名与特征作为标题，无需手动构思；
- **多场景设备分流（高级选项）**：
  - `1. 通用直接跳转`：全平台极速 302 重定向；
  - `2. 仅限微信内访问`：微信营销扫码专属，非微信访问展示友好引导；
  - `3. 仅限 iOS / 4. 仅限 Android`：按移动操作系统定向访问；
  - `5. 仅限手机浏览器`：微信内打开时自动弹出右上角「在浏览器打开」遮罩引导；
  - `6. 按设备分流`：单个短链接根据访客设备分别跳转不同链接（Android / iOS / Windows）；
- **访问统计与管理**：实时累计 PV、今日 PV 统计、一键启停开关、访问量清零、二维码弹窗与一键复制。

### 2. 👥 高可用微信群活码（qun）
- **多子码自动轮换**：支持添加无限个微信群子码，自定义设定每个群的进群上限阈值（如满 200 人自动平滑切换至下一个群）；
- **EdgeOne Blob 零配置自动托管**：调用官方 Blob SDK，首次上传图片由 SDK 自动创建存储，无需在控制台手动创建与配置；
- **7 天去重机制（Cookie）**：老用户扫码 7 天内固定展示首次扫码进入的群二维码，避免用户重复加群；
- **微信官方安全认证绿标**：页面顶部展示绿色安全认证标，提高微信内进群转化率；
- **客服微信兜底防流失**：当所有群子码全部满员时，自动无缝切换至客服个人二维码与引导文案，杜绝流量损耗；
- **真机模拟器实时预览**：控制台内置 iPhone 真机模拟器，无需扫码即可在后台直接预览真实微信进群界面。

### 3. 🖼️ Blob 素材库
- 支持直接上传图片、群二维码素材到 EdgeOne Blob；
- 一键复制图片永久直链并支持在线删除与管理。

## 🛠️ 腾讯云 EdgeOne 部署与配置说明

### 第一步：绑定 KV 键值数据库
1. 在 EdgeOne 控制台 **存储 > KV 存储** 新建一个命名空间（例如 `dwz_kv`）；
2. 在 Pages 项目的 **设置 > 存储绑定** 中，将该命名空间绑定至当前项目，**变量名填写 `DWZ_KV`**（代码中亦同时兼容 `MY_KV`、`KV`、`DB_KV`）。

### 第二步：Blob 对象存储（完全零配置）
- **无需手动在控制台创建或绑定**：EdgeOne Blob SDK 在系统首次上传图片或群二维码时会自动初始化创建 Store，全程自动化零配置。

### 第三步：关于 EdgeOne 预览域名 `*.edgeone.dev` 访问提示
EdgeOne 默认对 `.edgeone.dev` 预览域名开启了安全防刷与预览保护（未带签名直接访问会返回 `401: UNAUTHORIZED (eo_time missing)`）：
- **推荐做法**：在 EdgeOne Pages 控制台 **项目设置 > 访问控制 / 预览保护**，将「预览保护」**关闭**；
- **或通过控制台预览**：在 EdgeOne Pages 部署记录页面，点击右侧的 **「预览」** 按钮，系统会自动携带合法签名参数（`eo_token` / `eo_time`）访问；
- **或绑定自定义域名**：绑定自定义域名（例如 `dwz.yourdomain.com`）后，任何用户无需签名即可直接公开访问。
