# 🚀 引流宝 EdgeOne 原生版 (短网址 & 群活码)

本项目是专为 **腾讯云 EdgeOne Pages (Makers)** 打造的高性能轻量化私域流量管理系统。项目全面升级为 EdgeOne 云原生无服务架构，**严格精简仅保留「短网址」与「群活码」两大核心功能**。

数据库采用 **腾讯云 EdgeOne KV**（[产品文档](https://cloud.tencent.com/document/product/1552/127420)），文件与群二维码存储采用 **腾讯云 EdgeOne Blob**（[产品文档](https://cloud.tencent.com/document/product/1552/131425)），零服务器运维开销，依托全球边缘节点实现毫秒级响应。

## 🌟 核心特性

### 1. 🔗 智能短网址（dwz）
- **自定义短链 Key**：支持自主输入 2-32 位短链后缀或系统随机生成 6 位短链；
- **多场景设备分流**：
  - `1. 通用直接跳转`：全平台极速 302 重定向；
  - `2. 仅限微信内访问`：微信营销扫码专属，非微信访问展示友好引导；
  - `3. 仅限 iOS / 4. 仅限 Android`：按移动操作系统定向访问；
  - `5. 仅限手机浏览器`：微信内打开时自动弹出右上角「在浏览器打开」遮罩引导；
  - `6. 按设备分流`：单个短链接根据访客设备分别跳转不同链接（Android / iOS / Windows）；
- **访问统计与管理**：实时累计 PV、今日 PV 统计、一键启停开关、访问量清零、二维码快速生成与直链复制。

### 2. 👥 高可用微信群活码（qun）
- **多子码自动轮换**：支持添加无限个微信群子码，自定义设定每个群的进群上限阈值（如满 200 人自动平滑切换至下一个群）；
- **EdgeOne Blob 原生存储**：上传的微信群二维码直接存入腾讯云 EdgeOne Blob 分布式对象存储，全球 CDN 毫秒级回显；
- **7 天去重机制（Cookie）**：老用户扫码 7 天内固定展示首次扫码进入的群二维码，避免用户重复加群；
- **微信官方安全认证绿标**：页面顶部展示绿色安全认证标，提高微信内进群转化率；
- **客服微信兜底防流失**：当所有群子码全部满员时，自动无缝切换至客服个人二维码与引导文案，杜绝流量损耗；
- **真机模拟器实时预览**：控制台内置 iPhone 真机模拟器，无需扫码即可在后台直接预览真实微信进群界面。

### 3. 🖼️ Blob 素材库
- 支持直接上传图片、群二维码素材到 EdgeOne Blob；
- 一键复制图片永久直链并支持在线删除与管理。

## 🛠️ 腾讯云 EdgeOne 部署指引

### 第一步：创建 EdgeOne Pages 项目
1. 登录 [腾讯云 EdgeOne 控制台](https://console.cloud.tencent.com/edgeone/pages)；
2. 点击 **创建项目**，选择从 Git 仓库导入；
3. 绑定 GitHub 仓库：`https://github.com/pyzqj/dwz.git`；
4. 构建配置保持默认（纯静态与 Edge Functions 自动识别），点击开始部署。

### 第二步：配置 KV 键值数据库
1. 进入控制台左侧 **存储 > KV 存储**；
2. 新建一个命名空间（例如 `dwz_kv`）；
3. 进入项目设置中的 **存储绑定**，将上述命名空间绑定至当前项目，**变量名填写为 `DWZ_KV`**（系统亦兼容 `MY_KV`、`KV`）。

### 第三步：配置 Blob 对象存储桶
1. 进入控制台左侧 **存储 > 对象存储 (Blob)**；
2. 新建一个 Store，**名称填写为 `dwz-blob`**；
3. 将该 Store 绑定至当前项目。
